# Retained Isaac Sim 6.0.0 audit evidence

These files preserve publication-safe summaries from the production
measurement performed with NVIDIA Isaac Sim 6.0.0 and OpenUSD 0.25.11.
They support integrity and provenance review but are not presented as publicly
reexecuted results.

- `environment_summary.json` binds the runtime and opening contract.
- `domain_audit_summary.json` records the whole-Dream-AI containment result.
- `repeatability_summary.json` records the six-process repeatability result.
- `fresh_runs/*.summary.json` are the six state/attempt summaries.

The production Stages, resolver values, reverse maps, logs, and raw extraction
outputs are withheld. Public replay results are generated from
`data/publication_safe/`, not from these retained summaries.
